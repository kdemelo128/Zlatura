# Find and identify financial sections beyond the cover pages

An OM's parsed rent-roll section no longer becomes an OM-versus-lease/rent-roll type question. A per-page evidence index records rent-roll, statement, summary and unreadable pages; the staging card shows the original page numbers. Late rent-roll titles and joined header words are recognised. Explicit BOV/appraisal ambiguity remains a question. No financial formula, saved field, schema, library or network service is added.

Tested with synthetic fixtures only: 107 related unit tests, 18 phone/desktop browser checks, and archived-main regression failures; quick/type/golden checks pass with all 646 displayed figures unchanged. The shared full gate and corpus scoring remain required before readiness. Real owner documents, Safari, a physical phone and Microsoft Excel were not tested here.
