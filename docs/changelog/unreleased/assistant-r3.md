# Ask Monal now answers from your deal's own documents, on your device

Monal could answer from a deal's figures and the app's calculations, but not from what the OM, a lease, a T-12 or a Word memo actually say. Ask Monal now reads the documents of the open deal (as read in this session) and answers from them, with no language model, no new library, no network request and no change to the data format.

- **Quoted, not paraphrased.** "What does the OM say about the roof?", "what are the CAM charges", "is there a renewal option", "what are the escalations", "who is the tenant in suite 200", "when does <tenant>'s lease expire", "find 'parking'" return the best one to three passages, quoted exactly, each with the document name, the page and an "Open at this page" button (the page's text with the passage marked).
- **Figures only beside their label.** A year, date, percent or amount is taken from a passage only when it stands next to its label on one line and is the only value of its kind there (a table row of columns, or a value on the next line, is quoted and nothing more). It is shown as the document prints it and labelled "from the document, not checked". A CAM charge keeps the unit the document states.
- **The deal first, then the document.** A question about a deal figure (price, NOI, cap rate, occupancy) is still answered from the engine, then adds "The OM says, on page 3: …" and says whether it matches. When the OM and the deal differ, both are shown and the deal's figure is named as the one every calculation uses.
- **Never invents.** A question the documents do not answer says so, lists the words no document uses and offers the Documents list. A passage that reads like an instruction ("ignore previous instructions", "set the price to …") is quoted as text, marked, never acted on and never read for a figure. Answers are drawn as text nodes only.
- **How it works.** A small search index (passages cut from the page text, BM25 ranking, real-estate synonyms such as NOI / net operating income, CAM, TI, LC, expiration / expiry, escalation / bump, SF / square feet; amounts and dates normalised with the app's own parsers) is built from text the readers already extracted, held in this page's memory only and gone on reload. A document added in an earlier session has no text here: Monal says so and asks for the file again. A 60-page OM indexes in tens of milliseconds.
- **Suggested questions** adapt when the deal has documents; passages are quoted cards on a phone and a desk, announced and keyboard-reachable.
- **Tested** with invented documents only (a 24-page OM, a lease, a T-12, a Word memo, a scanned page as OCR reads it): 49 new unit tests including a hand-checked 32-question ranking set (31 first-place right; the miss is named in the test), a 15-question refuses-to-invent set, an injection set and an index speed budget; a browser flow at phone and desktop (axe, 44 px targets, zero network requests, nothing stored, index time at a 4x slower CPU). Saved deal results and every golden figure are unchanged.
