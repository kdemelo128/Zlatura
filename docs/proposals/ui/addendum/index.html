UI revamp addendum: mockups

Static pages for the addendum proposal. Every property, tenant, person and figure is invented. Nothing here is loaded by the app, and no page makes a network request: the fonts are local files (Source Serif 4 in fonts/ with its OFL licence, and the app's own Public Sans). Each page is one responsive file: under 960 px wide it is the phone layout, above it the desktop layout. Add ?theme=dark or ?theme=light to force a theme; otherwise it follows the system.

The approved wireframes of the base proposal are in the earlier set.
